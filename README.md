I'm a computer engineering student and this is where I keep my code while learning ML.

Started with numpy, pandas and matplotlib. Most of the pandas and matplotlib stuff uses a Pokemon dataset (data.csv) because it was more fun than the usual examples.

## Folders

- numpy-basics: array stuff, basic numpy functions
- pandas-basics: loc/iloc, filtering, mean/sum/min/max, groupby
- matplotlib-basics: bar chart of pokemon types, height vs weight scatter
